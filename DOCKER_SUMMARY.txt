🚀 БЫСТРЫЙ СТАРТ:

  Локально (разработка):
    npm install
    npm run dev
  
  Docker локально:
    docker-compose up -d
    → http://localhost:3000
  
  VPS (первый раз):
    # Установить Docker
    curl -fsSL https://get.docker.com | sh
    
    # Клонировать проект
    git clone <repo> /var/www/web-studio
    cd /var/www/web-studio
    
    # Запустить
    chmod +x deploy.sh
    ./deploy.sh production
    
    → http://your-vps-ip

💡 ПОЛЕЗНЫЕ КОМАНДЫ:

  Управление:
    make help                    # Все команды
    make docker-prod-up          # Запустить prod
    make docker-logs             # Просмотр логов
    make deploy                  # Деплой
  
  Docker Compose:
    docker-compose -f docker-compose.prod.yml up -d
    docker-compose -f docker-compose.prod.yml logs -f
    docker-compose -f docker-compose.prod.yml restart
    docker-compose -f docker-compose.prod.yml down
  
  Обновление на VPS:
    git pull origin main
    ./deploy.sh production
