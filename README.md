# Web Studio Landing Page

Brutalist editorial landing page following the Osmo Style Reference design system.

## Tech Stack

- **Next.js 15** — React framework
- **Tailwind CSS v4** — Styling
- **Lucide React** — Icons
- **TypeScript** — Type safety

## Design System

- **Style:** Brutalist editorial with concrete-gray canvas and stamp-printed typography
- **Palette:** Concrete (#f4f4f4), Ink (#201d1d), Volt Lime (#a1ff62), Ultraviolet (#6840ff)
- **Typography:** Compressed geometric sans with tight tracking
- **Radii:** Sharp (2px/5px) for content, extreme pills (1600px) for controls

## Getting Started

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Key Features

- Floating pill navigation bar
- Animated tech stack marquee
- Fanned portfolio cards with tilt effects
- Services grid with hover animations
- Featured case study card
- Full responsive design
